## The v2 thresholds

**TAU_LO_V2 = 0.20, TAU_HI_V2 = 0.65, TAU_TARGET_V2 = 0.75.** The rules are #202's: each over the grid, in priority order, each then the grid value closest to the middle of its gap (ties to the higher), **as if the code rules did not exist** (strength 5 and `HARD_MASS`, the section rule, the negation backstop), with a 0.5 floor on `TAU_HI`.

**The pin rule.** A write threshold of the context variant is never looser than v1's evidence-backed one while the variant's own would-be write set is thinner than v1's: `TAU_HI_V2 = max(fit, TAU_HI)` and `TAU_TARGET_V2 = max(fit, TAU_TARGET)` unless the set holds at least 29 would-be writes (v1's own, with the code rules off). Here it holds 3, so the rule applies: the fit alone gives `TAU_HI` 0.50 and `TAU_TARGET` 0.40, which become 0.65 and 0.75. A threshold fitted on 3 would-be writes sits where the rule leaves it (the floor, or below any evidence), which is not evidence that a looser cut is safe. `TAU_LO` is not a write threshold: it is fitted again below the pinned `TAU_HI_V2` (the fit alone gave 0.20).
